# web_security_analyzer
 Developed a Dark Pattern &amp; Security Analyzer using Python and Streamlit to detect manipulative design patterns and web vulnerabilities. 💻 Integrated SQL Injection, XSS, and port scanning detection with a dynamic safety score dashboard. 🚀 Built an elegant dark-themed UI to promote ethical web design and cybersecurity awareness.
A Streamlit-based web app that detects dark patterns, SQL Injection, XSS vulnerabilities, and open ports in websites.
It also generates a Safety Score Dashboard with an interactive gauge to visualize website security.

🚀 Features

Detects Dark Patterns in website design

Checks for SQL Injection and XSS vulnerabilities

Scans for open and potentially risky ports

Displays a Safety Score using a modern dark-themed UI

🧠 Tech Stack

Python 3

Streamlit

Requests, BeautifulSoup, Plotly
